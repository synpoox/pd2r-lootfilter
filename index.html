    Install by hand
    1. Open your D2R folder, then mods\PD2Resurrected\d2rloader\config\filter\. Create the filter folder if it is missing.
    2. Save the downloaded file there. Any name ending in .json works.
    3. In game: Esc → Options → Gameplay → Loot Filter Profile, pick your filter.

    Edits reload on save, or press Ctrl+Shift+F9. Hold Ctrl to pick up hidden items. A mod update can replace config\filter.json, so keep yours in the filter folder.
